有限域上的最小值与轨道证书

摘要

记 B(q,d) 为射影阻塞所需的最少平移数。四个有限实例的参数集、归一化和穷举方法列于下文。

Lean 核验四组最小值及 8、41、47 元域的最优解数。32 元域的轨道分类由两套 Python 枚举交叉核对。

8 元域32 元域41 元域47 元域

八元域上的二次曲线

取 F = 𝔽₂[t]/(t³ + t + 1)，d = 2。多项式在 0、1 处均非零，作为三次式不可约。由变次数篇 §1 的超平面判据，问题化为三维二元空间中的平面阻塞问题。一个仿射平面的补集恰为它的平行平面，故 S 击中所有平面当且仅当它仿射张成整个空间。

最小集就是仿射基，例如 {0, 1, t, t²}。有序选取仿射基的首点有 8 种，其余三点相对首点的差依次有 7、6、4 种选择。因此不同最小集数为 8·7·6·4/4! = 56。独立的 Lean 文件直接检查全部 256 个参数集和原始二次方程，给出同一答案。

四十一元域上的全部最优三次曲线族

取 F = 𝔽₄₁，d = 3。参数集的阻塞性在仿射变换 S ↦ uS + v（u ≠ 0）下保持不变。事实上，gcd(3,40) = 1，故可写 u = t³。变换 (x,y) ↦ (tx,t³y − v) 将参数 α 的图像送到参数 uα + v 的图像，并置换各条直线。因此任意两个不同的参数都能归一到 0 和 1。

可复核的有限判定

对每个 (m,b) ∈ F²，列出 Rm,b = {x³ + mx + b : x ∈ F}。这里对斜率和截距同时换号，仍枚举全部直线。共有 1,681 行。归一集已含 0、1，故凡含这两者中任一个的行都已命中，余下 182 行。对每个候选集，逐行检验其交集非空。以下伪代码给出整个判定。

R = [{(x³ + m·x + b) mod 41 for x in 0..40}
     for m in 0..40 for b in 0..40]
for k in {4, 5}:
    for D in combinations({2,…,40}, k−2):

为什么只有一个仿射轨道？

直接取五次单位根群 H = {1,10,16,18,37}。表中四个五元集（各补入 0、1）依次等于 2H+9、5H+33、3H+12、11H+30。因此所有最优集恰为 H 的仿射像。若 uH+v=H，对集合元素求和。因 ∑x∈H x=0，得 5v=0，从而 v=0。此时 uH=H 当且仅当 u∈H。稳定子大小为 5，轨道大小为 41·40/5=328。

四十七元域上的一个自由仿射轨道

令 F = 𝔽₄₇，A = {0, 1, 3, 15, 33}。Dot 提出了这一五元集及其分类的穷举结果。下面从逐线判据复算，并用稳定子另行推导轨道大小。

三次曲线的最小值与全部最优参数集

B(47, 3) = 5。最优集恰为 uA + v，其中 u ∈ F×，v ∈ F。每对 (u, v) 给出不同的集合。

固定一个参数。 平移参数集保持阻塞性。任一非空解都能平移为含 0 的解。对每个这样的候选集 S，预先计算各斜率的值集 Vm = {x³ − mx : x ∈ F}。由仿射直线判据，对于斜率 m，能被截到的直线恰有截距 b ∈ ⋃s∈S(Vm − s)。对全部 47 个斜率，这个并集都等于 F 时记录 S。

表中每行从其余 46 个元素中枚举相应大小的子集，再添入 0。若至多三个参数能阻塞，补足四个仍能阻塞，与第一行矛盾。第二行给出了五元解，故最小值为 5。

从 230 到 2,162。 计数带标记的解 (S, s)，其中 S 是五元解，s ∈ S。映射 (S, s) ↦ (S − s, s) 是到“含 0 的五元解 × F”的双射。每个 S 有五种标记，故五元解的总数是 230 · 47 / 5 = 2,162。

轨道与分类。 gcd(3, 46) = 1，故每个非零 u 都是某个 t³。沿用四十一元域的坐标变换 (x, y) ↦ (tx, uy − v)，得到 uA + v 亦为解。A 的元素和为 52 ≡ 5 (mod 47)，重心为 1。保持 A 的仿射变换固定重心，因而形如 x ↦ 1 + u(x − 1)。其乘子构成 F× 的子群，并在 A ∖ {1} 上自由作用，故阶整除 46 和 4。唯一可能的非平凡乘子是 −1，但它把 0 送到 2 ∉ A。稳定子遂为平凡群，轨道大小为 46 · 47 = 2,162，恰好穷尽全部最优解。

在仓库根目录运行 python checks/cubic47.py 可复核上表与仿射轨道。Lean 利用仿射对称性同时固定 0、1，在 990 个四元候选中得到 0 个解，在 14,190 个五元候选中得到 20 个解。上表列出的 230 个含 0 的解各含四个非零元素，乘法对称性使 46 个非零元素出现次数相同，故含 0、1 的解有 230 · 4 / 46 = 20 个。

三十二元域上的六次曲线

命题。 在 𝔽₃₂ 上，B(32,6)=7。共有 10,912 个七元最优参数集，分成 11 个仿射轨道，每个轨道的稳定子均平凡。以下取 𝔽₂[T]/(T⁵+T²+1)，用五位二进制数表示按幂次递增排列的系数。{0,1,2,3,4,19,31} 是其中一个最优集。

水平线由六次幂的双射性自动命中。置 V={ x⁶+x : x∈𝔽₃₂ }，则 |V|=16。每一非零斜率唯一写成 c⁵，换元 x=cz 把相应的直线条件化为 S 与 c⁶V+b 相交。由于六次幂也置换 𝔽₃₂×，这些集合就是 V 的全部仿射像。由 Ding–Tang [1，推论 30]，它们构成已知的 3-(32,16,112) 设计。所求最小值因而也是该设计中击中全部区组所需的最少点数。

数带一个标记点的七元解，得总数 2,387·32/7=10,912；数带两个有序标记点的解，同样得 462·32·31/(7·6)。逐一展开归一解的仿射轨道，得到 11 个两两不交的 992 元轨道，且其并等于全部解。在允许域自同构 x↦x² 的半线性仿射群 AΓL₁(32) 下，这 11 个轨道按 1+5+5 合并为三个，大小分别为 992、4,960、4,960。Dot 给出了此例及轨道数。python checks/sextic32.py 输出全部轨道代表和两次枚举结果。Lean 定理 Sextic32.pencil_minimum 核验射影原问题中的最小值 7，轨道分类的复现见上述程序。

在 𝔽₄₇ 取 S={0,1,3,5}。开集有 43·42=1,806 个有序点对。程序用多项式模幂判别三轮换，得到 18 个同时不可约点对；换回原坐标并直接代入所有域元素，得到 9 条斜率形如 3u² 的遗漏直线，每条恰出现两次。对每对不同平移，另在全部斜率上得到 16·15=240 条遗漏直线。
