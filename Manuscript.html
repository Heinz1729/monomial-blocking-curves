有限域上单项式曲线的
竖直平移与阻塞数

Asgarli–Ghioca–Yip 问题 5.4　｜　驯分歧情形的对数阶与有限域上的精确解

问题与主结果

在有限射影平面中，点集若与每条有理直线都有公共有理点，就称为阻塞集。设 F 是有 q 个元素的域，次数 d ≥ 2。对每个 α ∈ F 考虑射影曲线

Cα　:　YZd−1 = Xd − αZd。

在 Z = 1 内，每个参数 α 给出一条图像 y = xd − α。记 B(q, d) 为使这些曲线的有理点并集成为阻塞集所需的最少参数个数。Asgarli、Ghioca 和 Yip 在期刊版问题 5.4 提出求此数，并指出当 gcd(d, q−1) = 1 时，他们给出的对数下界论证不适用。[1]

固定次数的对数阶

固定 d ≥ 3，让 q 沿特征 p ∤ d(d−1) 的素数幂趋于无穷。第 7 节起证明 B(q,d) = Θd(log q)，下极限系数至少为 1/[2(d−1)log 2]。三次且 q ≡ 2 (mod 3)、p > 3 时，第 12–16 节同时计数斜率与截距，将下极限系数提高到 1/log 4。第 17 节给出上界 (2 log q − log log q)/log 3 + O(1)。本文的 log 为自然对数。

定理 1　Frobenius 次数的精确阻塞数

设 p 为素数，h, e ≥ 1，q = ph，d = pe。令 g = gcd(h, e)。则

B(ph, pe) = 1 + (h/g)(pg − 1)。

构造也可以显式给出。取子域 K = 𝔽pg，把 F 看作 K 上的向量空间。取一组基，每个基向量生成一条过原点的 K-直线。这些直线的并集就是最优的参数集。

定理 2　四十一元域上的三次曲线

B(41, 3) = 5。五次单位根 H = {1, 10, 16, 18, 37} 给出一个最优参数集。全部最优集恰为 uH + v，其中 u ≠ 0，共 328 个不同的集合。这个例子的特征为 41，立方映射不属于定理 1 的 Frobenius 子族。

四十七元域的情形。 同样有 B(47, 3) = 5。五元集 {0, 1, 3, 15, 33} 的仿射轨道给出全部 2,162 个最优解。第 5 节给出有限穷举与轨道计数。Lean 已验证最小值、分类与精确计数。

1　由射影直线化到子域上的超平面

仿射方程对 y 是首一的一次式，在代数闭包上不可约。齐次方程又无 Z 因子，故各曲线几何不可约。每条 Cα 在 Z = 0 上恰有一点 [0:1:0]。只要参数集 S 非空，无穷远线和所有竖直线已经被这个点阻塞。有限斜率直线 y = mx + b 不过此点。因此它被阻塞，当且仅当存在 x ∈ F 使 xd − mx − b ∈ S。空集对这两种检验都失败。这也是原文公式 (5.4) 的等价写法。[1]

引理 1　Frobenius 斜率的像

令 σ(x) = xpe，K 为 σ 的不动域。函数 Dm(x) = σ(x) − mx 是 K-线性的。设 W = im(σ − 1)。由于 ker(σ − 1) = K，由秩－零度定理，W 在 F 中的余维恰为 1。

若 Dm 的核为零，则 Dm 满射。否则取非零核向量 u，即 σ(u) = mu。对任意 z ∈ F 有

Dm(uz) = σ(u)(σ(z) − z)。

故 im Dm = σ(u)W。反过来，每一个非零 u 都对应斜率 m = σ(u)/u。由于 σ 为自同构，所有出现的非满像恰为 aW（a ∈ F×）。

引理 2　这些像给出所有超平面方向

选一个非零 K-线性泛函 λ，使 ker λ = W。映射 c ↦ (x ↦ λ(cx)) 从 F 到 K-对偶空间是线性的。若 c ≠ 0，则乘 c 为双射，所得泛函非零。此映射单射，且两边维数相同，因而是同构。每个非零泛函的核都是某个 c−1W。

让截距 b 跑遍 F，便得到这些线性超平面的全部仿射平移。结合引理 1，曲线阻塞条件化为

S 与 F 作为 K-仿射空间的每个超平面相交。

最后，F = 𝔽ph 上的 p-Frobenius 生成阶为 h 的循环伽罗瓦群。其 e 次幂的阶为 h/gcd(h,e)。由伽罗瓦对应，|K| = pg 且 [F:K] = h/g。

2　最优性与一个可手算的例子

引理 3　仿射阻塞数（Jamison，Brouwer–Schrijver）

设 K 有 Q 个元素，n ≥ 1。Kn 中与所有仿射超平面相交的点集，最少有 1 + n(Q − 1) 个点。[2, 3]

上界。取所有坐标轴的并集，它们只在原点相交，故恰有 1 + n(Q − 1) 个点。若 λ 是非零泛函，至少有一个基向量 ei 满足 λ(ei) ≠ 0。坐标轴上的点 (b/λ(ei))ei 就落在超平面 λ = b 上。

下界。平移一个阻塞集 S，使它含原点。用 · 表示标准坐标点积，在 n 个变量上构造多项式

P(X) = ∏s∈S∖{0} (1 − s · X)。

当 X = 0 时取值 1。当 X ≠ 0 时，超平面 s · X = 1 必含某个 s ∈ S，故 P(X) = 0。于是 P 在全部点上的值之和为 1。

若总次数小于 n(Q − 1)，则每个单项式至少有一个变量的指数 j < Q − 1。在该坐标上求和得到 0。当 j = 0 时，这是因为 Q 在 K 中为零。当 1 ≤ j < Q − 1 时，取乘法群生成元并对几何级数求和即可。因此低次多项式在全空间的值之和必为 0。矛盾！故 |S| − 1 ≥ deg P ≥ n(Q − 1)。代入 Q = pg、n = h/g，定理 1 得证。

固定 p、e 并令 h 增大时，答案为 1 + ((pg−1)/g) logp q。系数仅由 h 与 e 的最大公因数决定。这给出了原问题互素情形中的一条对数增长子族。

八元域上为什么恰有 56 个最优解？

取 F = 𝔽₂[t]/(t³ + t + 1)，d = 2。多项式在 0、1 处均非零，作为三次式不可约。引理 2 把问题变为三维二元空间中的平面阻塞问题。一个仿射平面的补集恰为它的平行平面，故 S 击中所有平面当且仅当它仿射张成整个空间。

最小集就是仿射基，例如 {0, 1, t, t²}。有序选取仿射基的首点有 8 种，其余三点相对首点的差依次有 7、6、4 种选择。因此不同最小集数为 8·7·6·4/4! = 56。独立的 Lean 文件直接检查全部 256 个参数集和原始二次方程，给出同一答案。

3　哪类线性化多项式有同一个阻塞数？

设 E/K 是有限域扩张，维数为 n，|K| = Q。给定 K-线性映射 T : E → E。我们称参数集 S 满足图像条件，若对每一对 m, b ∈ E，都存在 x 使 T(x) − mx − b ∈ S。这精确描述竖直平移图像对有限斜率直线的阻塞。

置 Dm(x) = T(x) − mx。文献称 T 为 scattered，如果所有 m 都满足 dimK ker Dm ≤ 1。这个条件就是说，满足 T(x)/x = m 的非零 x 至多占据一条 K-直线。[4]

定理 3　用任意平移参数集刻画 scatteredness

以下两条等价。(i) T 是 scattered。(ii) 对每个 S ⊆ E，S 满足图像条件当且仅当 S 与每个仿射 K-超平面相交。因此，对每个 scattered 映射，图像条件所需的最小参数集大小都等于 1 + n(Q − 1)。

图像条件总能推出超平面条件。 固定非零泛函 λ 和目标值 t ∈ K。由引理 2 中的对偶同构，存在 m ∈ E 使 λ(T(x)) = λ(mx) 对所有 x 成立。取 λ(v) = t。图像条件给出 s = T(x) − mx + v ∈ S，于是 λ(s) = t。

(i) 推出 (ii)。 若零度至多为 1，则每个 im Dm 由秩－零度定理可知是全空间或超平面。与每个超平面相交的集合非空，因而也与这些像的每个平移相交，这正是图像条件。

(ii) 推出 (i)。 假设某个 Dm 的零度至少为 2，则 W = im Dm 的维数至多为 n − 2。取 S = E ∖ W。每个仿射超平面的维数都是 n − 1，无法包含在 W 中，故必与 S 相交。但斜率取上述 m，截距取零，就有 Dm(x) ∉ S 对全部 x 成立。这与 (ii) 矛盾。最后的最小值由引理 3 得出。

定理陈述中的“每个 S”是必要的量词。反向证明专门选择了一个异常像空间的补集，构成能区分两种阻塞条件的参数集。

4　四十一元域上的全部最优三次曲线族

取 F = 𝔽₄₁，d = 3。参数集的阻塞性在仿射变换 S ↦ uS + v（u ≠ 0）下保持不变。事实上，gcd(3,40) = 1，故可写 u = t³。变换 (x,y) ↦ (tx,t³y − v) 将参数 α 的图像送到参数 uα + v 的图像，并置换各条直线。因此任意两个不同的参数都能归一到 0 和 1。

为什么只有一个仿射轨道？

直接取五次单位根群 H = {1,10,16,18,37}。表中四个五元集（各补入 0、1）依次等于 2H+9、5H+33、3H+12、11H+30。因此所有最优集恰为 H 的仿射像。若 uH+v=H，对集合元素求和。因 ∑x∈H x=0，得 5v=0，从而 v=0。此时 uH=H 当且仅当 u∈H。稳定子大小为 5，轨道大小为 41·40/5=328。

5　四十七元域上的一个自由仿射轨道

令 F = 𝔽₄₇，A = {0, 1, 3, 15, 33}。Dot 提出了这一五元集及其分类的穷举结果。下面从逐线判据复算，并用稳定子另行推导轨道大小。

定理 4　三次曲线的最小值与全部最优参数集

B(47, 3) = 5。最优集恰为 uA + v，其中 u ∈ F×，v ∈ F。每对 (u, v) 给出不同的集合。

固定一个参数。 平移参数集保持阻塞性。任一非空解都能平移为含 0 的解。对每个这样的候选集 S，预先计算各斜率的值集 Vm = {x³ − mx : x ∈ F}。由第 1 节，对于斜率 m，能被截到的直线恰有截距 b ∈ ⋃s∈S(Vm − s)。对全部 47 个斜率，这个并集都等于 F 时记录 S。

4C(46, 3) = 15,1800

表中每行从其余 46 个元素中枚举相应大小的子集，再添入 0。若至多三个参数能阻塞，补足四个仍能阻塞，与第一行矛盾。第二行给出了五元解，故最小值为 5。

从 230 到 2,162。 计数带标记的解 (S, s)，其中 S 是五元解，s ∈ S。映射 (S, s) ↦ (S − s, s) 是到“含 0 的五元解 × F”的双射。每个 S 有五种标记，故五元解的总数是 230 · 47 / 5 = 2,162。

轨道与分类。 gcd(3, 46) = 1，故每个非零 u 都是某个 t³。沿用第 4 节的坐标变换 (x, y) ↦ (tx, uy − v)，得到 uA + v 亦为解。A 的元素和为 52 ≡ 5 (mod 47)，重心为 1。保持 A 的仿射变换固定重心，因而形如 x ↦ 1 + u(x − 1)。其乘子构成 F× 的子群，并在 A ∖ {1} 上自由作用，故阶整除 46 和 4。唯一可能的非平凡乘子是 −1，但它把 0 送到 2 ∉ A。稳定子遂为平凡群，轨道大小为 46 · 47 = 2,162，恰好穷尽全部最优解。

在仓库根目录运行 python checks/cubic47.py 可复核上表与仿射轨道。Lean 利用仿射对称性同时固定 0、1，在 990 个四元候选中得到 0 个解，在 14,190 个五元候选中得到 20 个解。上表列出的 230 个含 0 的解各含四个非零元素，乘法对称性使 46 个非零元素出现次数相同，故含 0、1 的解有 230 · 4 / 46 = 20 个。

6　文献、优先权与形式证明

与已有结果的关系

2026 年 11 月 25 日的首版检索核对了原文问题 5.4 及其引用的相邻构造，另用 “vertical translates”、 “Frobenius graph”、 “scattered linearized polynomial”、 “affine blocking sets”、 “cubic intersection distribution” 和 “PG(2,41)” 等词交叉检索。原文已经给出逐线的值集判据，仿射超平面阻塞数和 scattered 多项式的核判据也已有文献。Bruen–Fisher 等较早的三次曲线阻塞构造允许选取不同曲线。Li–Pott 等工作研究单个图像与直线的交点数分布。[1–6]

在查到的资料中，未找到定理 1 的精确公式以本题的同一竖直平移族表述，也未找到定理 2 的五元最优集轨道分类。两者在本文均有可核验的证明。等价表述、未公开手稿及尚未被索引的成果仍可能存在，所以这是一份优先权待核的研究手稿。第 7 节起沿 Dot 建议的避碰斜率路线，确定驯分歧条件下的增长阶。一般参数的精确最小值与最佳渐近常数仍待确定。

7　非线性平移族的对数下界

以下 d ≥ 3 固定，q 为素数幂，p 为其特征，log 取自然对数。我们处理 p ∤ d(d−1) 的情形。这包含所有 p > d，允许特征固定而扩张次数趋于无穷。

定理 5　驯分歧情形的渐近阶

lim inf B(q,d) / log q ≥ 1 / [2(d−1) log 2]。
B(q,d) = Θd(log q)。

极限沿上述素数幂取。上界由 [1，定理 5.1] 给出。本节证明下界，并给出可代入有限 q 的充分条件。对任意 ℓ ≥ 1，记 n = (d−1)ℓ，h = gcd(d,q−1)。若下列两式同时成立，则 B(q,d) ≥ ℓ+1。

(7.1)　q−1 > h(d−1)(d−2) ℓ(ℓ−1)/2，
(7.2)　q−n > (n−1)(2n−1)√q。

选取斜率

固定任意 ℓ 元参数集 S ⊂ 𝔽q。在直线 y = mx + b 上，与第 α 条曲线相交等价于多项式 xd−mx−(b+α) 有域内根。取 m = dud−1，u ∈ 𝔽q×。在代数闭包上，映射 x ↦ xd−mx−α 的临界点恰为 uζ，其中 ζ 遍历 (d−1) 次单位根，各为单临界点。对应的有限分支值为 (1−d)udζ−α，同一映射内两两不同。

给每一无序参数对 α、β 固定顺序。碰撞要求 (1−d)ud(ζ−η) = α−β，故 ζ ≠ η。每对有序单位根最多排除 h 个域内非零 u，即使单位根本身只在扩域里也成立。(7.1) 保证可选 u，使全部 n 个有限几何分支点两两不同。

特别地，三次且 q ≡ 2 (mod 3) 时有限分支点为 ±2u³−α。此时立方是双射，故只要 |S−S| < q，便可令 4u³ ∉ S−S。下面固定一个满足避碰条件的斜率。

8　分支、独立性与常数域

记 k 为 𝔽q 的代数闭包，以 b 为超越元。令 Lα 为 xd−mx−α−b 在 k(b) 上的分裂域。原映射 ℙ¹ → ℙ¹ 可分且次数为 d，故在 d 根上的单值作用传递。每个有限分支纤维恰有一个二重点，其余点不分歧。无穷远处唯一的点分歧指数为 d。这些指数均与 p 互素。局部极大驯分歧扩张对取共轭及复合封闭，故伽罗瓦闭包与下文全部复合仍处处驯分歧。这里允许 p 整除 d!。

单个覆盖的群

在单值群中取所有有限点惯性群的共轭生成的正规子群。商覆盖只可能在 ∞ 驯分歧。事实上，若次数 a > 1 的连通可分覆盖只在 ∞ 驯分歧，且其上有 t ≥ 1 个几何点，Riemann–Hurwitz 给出 2g−2 = −2a+(a−t) ≤ −a−1 < −2，矛盾。因此商平凡。每个有限惯性生成元在根上是一个对换。由对换生成的传递群是 Sd：将每个对换看作两根间的一条边，每一连通分量上的边对换生成其全对称群，而传递性迫使图连通。

平移之间的独立性

逐一加入分裂域。Lα 与此前分裂域之复合的交域在任何有限点都不分歧，因为两侧的有限分支集不交。交域在 ∞ 仍为驯分歧，由上段它等于 k(b)。有限伽罗瓦扩张的交域判据遂给出几何群 G = (Sd)ℓ。在 𝔽q(b) 上，各多项式分别有定义，算术群忠实地嵌入同一乘积，又包含几何群。因此两群相等，分裂域的常数域恰为 𝔽q。

还可算出这个完整伽罗瓦覆盖的亏格。令 D = (d!)ℓ。各有限惯性阶为 2。∞ 处几何驯惯性为循环群，生成元在每一因子中都投为阶 d 的元，故在乘积中仍为阶 d。于是

2g−2 = D[n/2−1−1/d]。

Kurlberg [10，命题 8] 已用有限分支集不交证明平移分裂域独立并控制常数域。Pollack [11，引理 8(ii)–(iv) 及其证明] 在同时不可约特化中处理了共用的无穷远驯分歧。Kurlberg–Rosenzweig [7，推论 16] 进一步对一般多项式加线性项，避开给定平移差所致的碰撞。(7.1) 对单项式直接数出例外参数 u 的上界。

已有估计给出的下界。 令 C 为各分量都是 d-轮换的共轭类，|C| = ((d−1)!)ℓ。在去掉所有分支点的开曲线 U 上，Zywina [8，命题 5.1] 已给出 |N−#U(𝔽q)/dℓ| ≤ (n−1)√(|C|q)。置 A = d√((d−1)!)。对任意 0 < c < 1/(2 log A)，取 ℓ = ⌊c log q⌋，则 (n−1)Aℓ = o(√q)，(7.1) 保证避碰，上述估计保证 N > 0。这已给出对数阶。三次情形的下极限至少为 1/log 18。下一节利用这个共轭类的特征标，将下界提高到 1/log 16。

9　同时不可约的显式误差

从 ℙ¹ 去掉 n 个有限几何分支点和 ∞，得定义在 𝔽q 上的开曲线 U。令 N 为使全部 ℓ 个多项式同时不可约的 b ∈ U(𝔽q) 的个数。因子次数等于 Frobenius 在根上的循环长度，故每个分量均须为 d-轮换。每个这样的 b 给出一条避开曲线并集的直线。对于一般次数，这一充分条件已足够。

|dℓN − #U(𝔽q)| ≤ (n−1)(2n−1)√q。

特征标。 取 Sd 在特征零系数上的标准表示 V（置换表示的坐标和零子空间）。若置换有至少两个循环，则 V 含特征值 1。对单个 d-轮换，V 上的特征多项式是 (Td−1)/(T−1)。代入 T=1 得

d · 1d-轮换(σ) = det(1−σ | V) = ∑j=0d−1(−1)j tr(σ | ∧jV)。

对 ℓ 个独立因子相乘。全取 j=0 的项贡献 |U(𝔽q)|。其余每个外张量积均无几何不变向量：V 本身无不变向量。当 j ≥ 2 时，在置换表示的第 j 外幂中，交换任意给定基指标集中的两个指标，会使该基楔积的系数变号，故不变向量的每个系数均为零。∧jV 嵌入此外幂。几何群为直积，因此只需一个因子无不变量。

迹估计。 对上述非平凡项取辅助素数 λ ≠ p，令 W 为相应的秩 a 的 λ 进局部系统。有限单值保证逐点纯权 0。U 非完备且连通，故紧支撑 H0 为零。由对偶性及特征零有限群表示的半单性，无几何不变量也无余不变量，故紧支撑 H2 为零。各 Swan 导子均为零。Grothendieck–Ogg–Shafarevich 公式给出 χc(Uk,W) = a(2−(n+1))。因此紧支撑 H1 的维数是 (n−1)a。由迹公式和 Deligne 权界，单项特征标和的绝对值至多 (n−1)a√q。[8，命题 5.1 的逐特征标估计]

所有外张量积的秩之和为 (∑j C(d−1,j))ℓ = 2n。扣除平凡项的秩 1，再用三角不等式即得框中估计。这对每个 S 和每个使分支分离的 u 同时成立。由 #U(𝔽q) ≥ q−n，(7.2) 推出 N > 0。阻塞性在添入参数后保持，故 (7.1)–(7.2) 蕴含 B ≥ ℓ+1。

推论 6　固定斜率给出的三次下界与随机上界

1 / (4 log 2) ≤ lim inf B(q,3)/log q
≤ lim sup B(q,3)/log q ≤ 2 / log 3。

这里 p > 3 且 q ≡ 2 (mod 3)。证明较好的上界需计入每个非零斜率。设 f(x)=x³−mx，m ≠ 0。令 E 为 3x²=m 的解数。恰有 E 个纤维含两个不同有理根：其一为二重根，第三根由系数确定。不同临界点有不同临界值。设 t 为含三个不同有理根的纤维数。

有序碰撞对 x ≠ y 满足 x²+xy+y²=m。取本原三次单位根 ω ∈ 𝔽q²，因为 ω ∉ 𝔽q，左端正是 x−ωy 的范数。非零范数的纤维有 q+1 个点，去掉对角线上的 E 点，得 2E+6t=q+1−E。故像集大小为 q−E−2t=(2q−1)/3。这也与 Dickson 多项式的已知值集公式相符 [9]。

水平线被单个平移全部截到。对余下 q(q−1) 条直线，取 ℓ 个独立随机平移，未截直线数的期望为 q(q−1)[(q+1)/(3q)]ℓ。若它小于 1，便有一个至多 ℓ 个参数的阻塞集。取极限即得上界。

三次下界与 Pollack 的结果

取 p > 3，固定任意 ℓ 元集 S。在 [11] 中取外层多项式 fα(T) = T−α，代入次数取 3。由其引理 6，满足判别式条件的 h(T) = T³+aT²+eT 至少有 q²−36q(1+ℓ(ℓ−1)/2) 个。对每个这样的 h，其推论 15 给出 g ≤ 3ℓ6ℓ，而式 (4.4) 前的逐个 h 估计给出：使 h(T)−v−α 对所有 α 同时不可约的 v 的个数，至少为

3−ℓ[q−2(g√q+g+6ℓ)]−2ℓ。

若 ℓ = ⌊c log q⌋，0 < c < 1/(2 log 6)，则 ℓ6ℓ = o(√q)。上述两个下界对充分大的 q 均为正。代换 T = x−a/3 将 h(T)−v 化为 x³−mx−b，保持每个平移的不可约性。故仅由 [11] 即可推出三次阻塞数的下极限系数至少为 1/(2 log 6)。第 9 节用逐特征标估计将此系数提高到 1/(4 log 2)。

tα = 2(v+w+2α)/(v−w)。

13　二点配置空间的单值作用

先在复数上计算；第 15 节说明向特征 p 的转移。令 A = (−S) ∪ {∞} 为球面上的 ℓ+1 个标记点，U 为补集上两个不同动点的有序配置空间。以 i 标记一个点 ai，其中有限标记的平移为 α=−ai。令 G=π₁(U)。

两组生成元

选择动点的基点 v₀、w₀。把全部标记置于一个拓扑赤道上，取两组扇形弧，分别从一个半球内的 v₀ 和另一半球内的 w₀ 连到每个标记。同侧弧内部两两不交，异侧弧只有同标记的端点才相遇。沿弧来回并绕标记一周，另一动点保持不动，得到子午圈 xi、yi。不同标记的异侧两圈可在互不相交的小管内同时运动，故

xiyj = yjxi　(i ≠ j)。　(13.1)

这两组圈生成 G。忘记 v 的映射是配置空间纤维化 [13]。固定 w₀ 的纤维是从球面删去 A 和 w₀；沿第一组弧绕 A 的圈生成其基本群（绕所余一点的圈由球面的周界关系给出）。第二组圈投影后生成底空间基本群。由纤维化的正合列即得断言。下面只用生成性和 (13.1)。

每个三次因子中的两个对换

在有限标记 i 对应的因子上，归一化三次覆盖的分支值为 t=±2、∞，惯性型依次为对换、对换、三轮换。固定 w 后，v ↦ tα 是分式线性同构。v=ai、∞、w 对应这三个分支值；其他有限标记处无分歧。因此有限圈 xi 只在第 i 因子上作用为对换 Ai，同理 yi 只在那里作用为对换 Bi。在这一因子上，x∞ 也是对换；它与 yi 交换，故等于 Bi。该纤维上的三次单值群为 S₃（连通三张覆盖且含一个对换）。它由 Ai 与 x∞ 的像生成，故 Ai ≠ Bi。每对有限圈由此生成单独的第 i 个 S₃，几何群为 (S₃)ℓ。

14　与张量秩无关的一阶上同调界

各因子取平凡表示、符号表示或二维标准表示，作外张量积 W，系数为特征零。写 b₁(W)=dim H¹(U,W)。我们证明

b₁(W) ≤ 6ℓ+2；若至少三个因子为符号表示，则 b₁(W)=0。

一阶上同调由 G 的交叉同态 D(gh)=D(g)+gD(h) 模去余边界 D(g)=(1−g)z 计算。对有限标记写 ui=D(xi)、vj=D(yj)。沿用 Ai、Bj 表示它们在 W 上的作用。(13.1) 给出

(1−Bj)ui = (1−Ai)vj　(i ≠ j)。　(14.1)

将 ui 投到 W/im(1−Ai)。该类被所有 Bj（j ≠ i）固定。局部商维数至多 1，其他每个因子的固定空间也至多一维，故投影的自由度至多 1。交换两方向同理。全部 2ℓ 个投影至多贡献 2ℓ 维，且均消去余边界。

投影的核。 此时 ui=(1−Ai)Pi，vj=(1−Bj)Qj。在每个标准因子取基 e、f，分别张成两对换的固定线；它们不同，因为两对换生成 S₃ 且标准表示无不变量。对每个张量基词 ξ，在 Pi 模 ker(1−Ai) 中，其系数仅在第 i 位为 f 或符号因子时保留；在 Qj 中，保留条件为 e 或符号因子。(14.1) 令两类保留系数在 i ≠ j 时相等：两算子作用在不同位置，其乘积的核正是两个核之和。

固定 ξ，以保留的 P、Q 系数为两侧顶点，不同指标间连边。若 ξ 中同时有 e 和 f，相应两个不同指标相连，所有符号顶点也都接到这个连通分量。所有系数遂相同，可用一个余边界的 ξ 系数同时消去。至多两个常值词尚待处理（无标准因子时仅一个空词），各有至多 2ℓ 个顶点，总贡献至多 4ℓ。有限圈数据给定后，若两个余循环具有相同数据，其在 x∞ 上的差由 (13.1) 被全部 Bj 固定，维数至多 1；y∞ 同理。这就得到 6ℓ+2。

三个符号因子。 在这些指标上两种圈均作用为 −1。(14.1) 给出 ui=vj（i ≠ j）。至少三个指标时，删去同指标边的完全二部图连通，用一个余边界可使它们全零。每个其余生成元都与对侧某个这样的圈交换，由交叉同态关系，其值也为零。这证明了消没断言。

15　正特征比较与曲面的迹估计

取辅助素数 2，在 ℚ₂ 上计算。第 13 节的各个 S₃ 表示有不变 ℤ₂ 格。把标记提升到混合特征离散赋值环中互不相交的截面。例如对非零有限标记取单位根提升，∞ 取无穷远截面，若 0 在标记集中则提升为 0。在 ℙ¹×ℙ¹ 的相对模型中删去相应的竖线、横线和对角线。于每个三重交点 (a,a)、a ∈ A，沿该截面吹起一次，得到光滑固有紧化，边界为相对简单正规交叉除子。三次分裂覆盖在开集上由同一批方程定义且有限平展，群的阶仅有素因子 2、3，故在边界驯分歧。

SGA 1 的驯专化定理 [14，XIII，推论 2.9 与 §2.10] 将此正规交叉对的几何基本群的素于 p 商与几何特征零纤维对应。对格模 2h 的一阶余循环，所需有限群嵌入格的加法群与 (S₃)ℓ 的半直积，其阶仍与 p 互素。故该专化保留一阶上同调和上述单值作用。取逆极限后张量 ℚ₂，结合复比较，得到第 14 节在 𝔽̄q 上的两个结论。这里仅转移一阶上同调。由于各多项式在 𝔽q 上有定义，算术群也在同一乘积中，因而等于满几何群。

二阶和三阶分别估计

设 W 是一个非平凡的上述张量积，秩为 r，b₁=b₁(W)。这些表示自对偶。U 是光滑仿射曲面（平面中一个主开集），故由仿射消没与对偶，紧支撑 H⁰ 和 H¹ 为零，H³ 的维数为 b₁。几何直积无 W 不变量，故紧支撑 H⁴ 为零。

令 Y 为平凡化各表示的有限几何伽罗瓦覆盖。每个非恒等甲板变换均无不动点，且阶与 p 互素。Deligne–Lusztig 的有限阶不动点公式 [15，定理 3.2] 使它在 Hc∗(Y) 上的交错迹为零。虚特征标遂为正则特征标的倍数；取群不变量得该倍数为 χc(U)。于是 χc(U,W) = rχc(U)。由乘法性和删去对角线，χc(U) = (1−ℓ)²−(1−ℓ)=ℓ(ℓ−1)。所以紧支撑 H² 的维数恰为 rℓ(ℓ−1)+b₁。

有限单值使局部系统逐点纯权 0。迹公式和 Deligne 权界 [16] 从而给出单项误差

|∑(v,w)∈U(𝔽q) tr(Frobv,w | W)| ≤ rℓ(ℓ−1)q + b₁(q+q3/2)。

16　汇总误差与首项系数

在 S₃ 上，三轮换示性函数的三倍为 1+sgn−std，其中 std 指二维标准表示的特征标。对 ℓ 个因子相乘，每个有序点对的乘积恰为 3ℓ 乘同时不可约的示性函数。全平凡项的和为 (q−ℓ)(q−ℓ−1)。其余项的秩之和为 (1+1+2)ℓ−1 = 4ℓ−1。

第 15 节的 q3/2 项由一阶上同调控制。含至少三个符号因子的张量项在此贡献零。余下至多 Mℓ 项：选 j 个符号位置，其余位置各有平凡与标准两种选择。每项分别用 6ℓ+2 作维数上界，无须乘以该表示的秩。逐项相加即得 (12.1)。整个推导对 S、ℓ 和允许的 q 一致。

任取 0 < c < 1/log 4，令 ℓ=⌊c log q⌋。将 (12.1) 除以 q²，误差至多为

O(ℓ²4ℓ/q + (ℓ+1)³2ℓ/√q) = o(1)。

主项除以 q² 趋于 1，故对任意 ℓ 元集都有遗漏的直线，B(q,3) ≥ ℓ+1。令 c 递增到 1/log 4 即得定理 7。这里的优点来自把最高的非平凡权项控制在多项式乘 2ℓ；若对它也使用总秩 4ℓ，只能恢复推论 6 的较小下界。

与三次多项式相关计数的关系

Pollack 的一般同时不可约估计与本题的三次归约见第 10 节。Bary-Soroker 的大有限域元组定理 [17] 在固定次数、固定平移数时给出渐近式。Bary-Soroker 与 Stix [18] 对两平移给出精确计数，Gorodetsky 与 Sawin [19] 研究两因子相关及其误差。在本题中，两平移的全斜率计数亦有直接校验：遗漏参数集大小恒为 h=(q+1)/3。由平移及立方缩放，仿射群在有序相异参数对上二重传递；对 q(q−1) 条非水平线作双计数，每对参数恰有 h(h−1) 条遗漏线。

Cohen–Dimca–Orlik 的超平面配置非共振定理 [20，定理 1] 在适当单值假设下给出消没。考虑恰好两个标准因子、其余平凡的项。在 (v,w) 平面的射影闭包中，每条竖线、横线的惯性均有特征值 1。对角线的两因子均为三轮换，二者张量含特征值 1。无穷远直线的一般点处各 tα 取非分支值，惯性平凡。因此没有一条边界直线满足 [20] 对该直线本身的非共振条件。第 14 节的维数上界也处理这类项。

定理 7 需要对指定的任意 ℓ 元集控制两参数计数，且 ℓ 随 q 增长。此次查到的上述论文没有给出 (12.1)、第 14 节的张量一阶维数界或相应的阻塞系数。这里的优先权判断限于已检索的文献。checks/cubic_pairs.py 对小素域独立比较有序点对、三轮换和原始直线。第 12–18 节为数学证明。

17　上界的对数对数改进

令 q ≡ 2 (mod 3)，且特征 p > 3。第 10 节用随机平移覆盖直线。若允许第一步留下少量直线，再用一个参数同时击中它们，可以得到

B(q,3) ≤ (2 log q − log log q)/log 3 + O(1)。

给定直线的共同参数

给定 t ≥ 1 条有限斜率直线 y=mix+bi。记 Gt=2+(2t−1)3t。若 q+1−Gt√q > 3t，则存在一条 y=x³−α 同时击中这些直线。这个充分条件对全部斜率和截距一致。

写 fi(x)=x³−mix−bi。所求是方程 f1(x1)=⋯=ft(xt)=α 的一个仿射有理解。在 ℙt 中将前 t−1 个等式齐次化为

Xi³−X1³−(miXi−m1X1)Z²−(bi−b1)Z³=0　(2 ≤ i ≤ t)。

无穷远有有理点 P=[1:⋯:1:0]。在 X1=1 的图中，各方程关于 X2,…,Xt 的导数矩阵在 P 为 3 倍单位阵。因此 P 是光滑曲线点，Z 是局部参数。过 P 的唯一几何不可约分支由 Frobenius 保持。取其在 𝔽q 上的光滑射影模型 C。函数 α=f1(X1/Z) 在 P 有极点。用 t 个三次方程逐一添根，得到映射 α: C → ℙ¹ 的次数 D ≤ 3t。

各 fi 的有限临界值至多两个。其分裂域复合的几何群嵌入 (S3)t，群阶与 p 互素。因此 α 为可分驯覆盖，并且至多有 2t+1 个几何分支值（含 ∞）。每个分支值对 Riemann–Hurwitz 公式的贡献至多 D，故 2g(C) ≤ 2+(2t−1)D ≤ Gt。Hasse–Weil 界给出至少 q+1−Gt√q 个有理点，其中位于 ∞ 上方的至多 D 个。在其余点，xi 都满足关于 α 的首一方程，故均无极点，其剩余值给出所求解。整个论证容许不同三次映射有相同的有限分支值。

随机取样后再补一个参数

置 t=⌊log q/(4 log 3)⌋。对充分大的 q，有 t ≥ 1、3t ≤ q1/4，上面的充分条件成立。每次均匀独立抽取一个参数，对指定非水平有限斜率直线，遗漏概率是 (q+1)/(3q) [第 10 节]。取

k = ⌈log(q(q−1)/t)/log(3q/(q+1))⌉。

遗漏直线数的期望至多 t，故某次取样至多遗漏 t 条。用上述引理补一个参数即可。水平线因立方映射为置换而已被击中，竖直线与无穷远线经过共同点 [0:1:0]。于是 B(q,3) ≤ k+1。由 log t = log log q + O(1) 及 log(3q/(q+1))=log 3+O(1/q) 得框中式。此改进节省的参数数目随 q 增长，上界的首项系数仍为 2/log 3。

18　特征 2 的适用范围

二元特征下，满足 q ≡ 2 (mod 3) 的域阶为 q = 22h+1。此时固定斜率 1 即可处理唯一的有限野分支点，得到下列补充界。奇特征部分的二维估计使用两个不同的有限分支值。

1/log 16 ≤ lim inf B(q,3)/log q ≤ lim sup B(q,3)/log q ≤ 2/log 3。

野惯性。 在代数闭包上取三次本原单位根 ω，令 x=z+z−1。Dickson 恒等式给出 t=x³+x=z³+z−3。六次映射 z ↦ t 的自同构由 z ↦ ωz 和 z ↦ z−1 生成，故三次方程的分裂域有几何群 S₃。∞ 处惯性阶为 3，唯一有限分支值为 0，其上三个点由旋转互换。在 z=1 取局部参数 u=z−1，惯性对换 σ 为取逆，满足 σ(u)=u/(1+u)。因 σ(u)−u 的赋值为 2，这个二次野惯性群的唯一上跳为 1。

固定斜率的估计。 给定 ℓ 个互异参数 α，以 b+α 代 t。各有限分支值互异，各交域至多在 ∞ 驯分歧，故第 8 节的 Riemann–Hurwitz 论证给出直积群 S₃ℓ 及常数域 𝔽q。删去 ℓ 个分支截距，令 N 为剩余截距中使全部三次式不可约的个数。第 9 节每个非平凡秩 a 项在有限分支处的 Swan 导子至多为 a，在 ∞ 为零。由 Euler 特征公式，dim H¹c ≤ (2ℓ−1)a。秩和为 4ℓ−1，故

|3ℓN−(q−ℓ)| ≤ (2ℓ−1)(4ℓ−1)√q。

对每个 0 < c < 1/log 16，取 ℓ=⌊c log q⌋，右端为 o(q)，故有遗漏直线。上界沿用第 10 节的范数计数。对非零斜率 m，碰撞方程 x²+xy+y²=m 有 q+1 个有序解，恰有一个位于对角线。纤维 x³+mx=0 恰由简单根 0 与二重根 √m 组成，其余有多个域内根的纤维各含三个单根。因此值集大小仍为 (2q−1)/3，随机平移给出框中上界。

上界的次阶项。 第 17 节的光滑点在此特征仍满足同一雅可比判据。用 Castelnuovo–Severi 不等式估计过此点的分支亏格（亦见 [11，§4]）。在几何常数域 k 上令 Fi=k(α,x₁,…,xi)。F₁=k(x₁) 为有理函数域，Fi 是 Fi−1 与 k(xi) 的复合，对两者次数分别至多 3、3i−1。故 gi ≤ 3gi−1+2·3i−1，归纳得 gt ≤ 2(t−1)3t−1。所以 2gt ≤ Gt；同一补点引理与随机取样仍给出 (2 log q − log log q)/log 3 + O(1) 的上界。

这是第 9 节特征标估计在一个野分支点上的应用，系数取自固定斜率。此处辅助素数取异于 2 的素数。[7，定理 13] 假设 p ∤ d(d−1)。Carmon 在特征 2 研究平移的相关性及通用分裂域。[9] 给出 Dickson 值集的一般公式。Carmon（2015）。
